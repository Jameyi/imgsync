# Migration notes (from the starter base)

ImgSync is a rebrand of the wangrunlin/seo-nextjs-starter v1.0.0 skeleton (MIT). If you are tracking upstream changes, note:

1. Site identity defaults moved from "SEO Next.js Starter" to ImgSync (`src/config.ts`, `.env.example`).
2. Repository/template/deploy URLs are placeholders (`your-name/imgsync`) until the real repository is created.
3. Dev server port is fixed at 6553 (`pnpm dev`).
4. Product direction and module boundaries live in docs/PRD.md and docs/CODING_RULES.md; the starter's SEO demo pages (`/examples/**`) are kept only until the `/tools/[slug]` routes land.
